# 練習機能の仕様

## 目的
スクランブルで手元のパズルを崩し、解くタイムを測って、PLL・OLL を覚えているかを確かめる。
目安の時間（しきい値）以内に解けたケースは自動で「習得済み」、超えた・解けなかったケースは「練習中」にする。

## データ
- 元データ：`data/pll/scrambles.json`・`data/oll/scrambles.json`（`{ ケース番号: [スクランブル, ...] }`。ケース番号は `algs_info.json` と同じ）
- 生成：`node tools/build-pll-data.js`・`node tools/build-oll-data.js` で、`js/pll-data.js` などと一緒に `js/pll-scrambles.js`・`js/oll-scrambles.js`（`window.PLL_SCRAMBLES = { "A1+": [...] }`）を作る（`tools/scrambles-lib.js`）
  - 各スクランブルで崩した状態が、そのケースになる（既定の手順で AUF を除いて揃う）かを確かめ、だめならエラーで止める（`js/case-check.js` の `fitSetup`）
  - 記法は読み替える（`Br` → `BR` など）
  - 練習ページだけが読み込む（エディタ・一覧は重くならない）

## 練習ページ（`practice.html`・`js/practice.js`・`css/practice.css`）
- 設定
  - 種類：PLL / OLL。OLL のときは範囲：No Dot / Dot / All（この2つは見出し「練習」の横に置き、下の設定の行を1行に収める）
  - グループ：「すべてのグループ」または選んだグループ（例：`A, B`）。押すとグループのボタン（A〜Z、1〜53 など。範囲に入るものだけ）が並ぶ欄が開き、押したグループだけを出題する（1つも選んでいなければすべて。「選択を解除」で戻す）。グループのボタンにマウスを乗せると特徴とケースの数が出る。PLL・OLL それぞれで覚えておく
  - PLL は欄の上で「グループ順 / 覚える順」を切り替えられる（一覧ページと共通。`reference/PLL_SPEC.md`「覚える順番」）。覚える順では、グループのボタンが覚える順番の段階（F1、A1–2、… X1–7 の 27）になり、それを選んで出題する（欄の名前は日本語では「グループ」のまま、英語では Stages）
  - 対象：未習得 / 練習中 / 習得済み / すべて（それぞれ件数付き。範囲・グループで絞った中の件数）
  - 習得の目安：5秒 / 8秒 / 10秒 / 15秒、または入力欄に数値（1〜120 秒）。入力した秒数はボタンには足さず、入力欄を強調する。PLL と OLL で別々に持つ（例：PLL は 8 秒、OLL は 5 秒）。既定は 8 秒
  - 出題：苦手を多めに / ランダム（PLL・OLL 共通。既定は苦手を多めに）。苦手を多めにでは苦手なケースほど出やすくし（下の「出題」）、ランダムではどのケースも同じ確率。変えても今の問題はそのまま
- 出題：対象に当てはまるケースからランダム（直前と同じケースは避ける）。設定の出題が「苦手を多めに」なら、どの対象でも苦手なケースほど出やすくする（苦手な順に出すのではなく、確率に差をつける。習得済みでも危ういケースが多めに出る）：苦手の度合いは記録のページの苦手順と同じ（`Progress.weakScores`：その種類の直近 10 回の平均、解けなかった回は目安の 2 倍、回数の少ないケースは全体の平均で 2 回解いたものとして足す）で、重みは（度合い ÷ 習得の目安）を 0.5〜3 に収めて 2 乗（0.25〜9）。まだ解いていないケースは解けなかったのと同じ扱い（目安の 2 倍 → 重み 4）にして、苦手なケースと同じくらい出るようにする（PLL の「すべて」で、151 ケースが一通り出るまで約 460 問。ランダムでは約 830 問）。記録が1つも無ければすべて同じ確率。選んだケースのスクランブルからランダムに選び、前後にランダムな AUF（それぞれ 0〜4 回）を足す（もともと前後にある U とはまとめる。例：`U R … U'` に前 U・後 U を足すと `U2 R …`）。前後の AUF を足しても同じケースのままで、崩れ方の向きが毎回変わる。ケースの名前と画像は解き終わるまで出さない。対象が0件なら「対象のケースがありません」
- タイマー
  - スペースキーを押した瞬間にスタート（画面ではタイマーの数字をタップした瞬間）。計測中は数字を青にする
  - 計測中は何かのキー（画面ではどこかをタップ）でストップ。Esc は中止（記録せず、同じスクランブルのまま）
  - 計測中に「スキップ」を押すと、タイムを記録せずに次の問題へ（習得済みにはならない）。「解けなかった」を押すと、タイムを記録せずに練習中にする
  - 止めてから 2 秒はスタートしない（止めた直後に続けてキーを押して、次の計測を始めてしまわないように）。その間はタイマーの数字を赤にする（目立つように）。通しの長押し・インスペクションも同じ。ボタン（解けなかった・スキップなど）は 0.4 秒のあとは押せる
  - キーの押しっぱなしによる繰り返しは無視する（スタートしたスペースを押し続けても止まらない）
  - 計測中は説明（とヒント）を隠す。スクランブルは計測中も出したまま。止めたタップでそのままボタンを押さないよう、止めてから 0.4 秒はボタンを無視する
  - 止めたあとはタイムを 0.00 に戻さず、次の計測が始まるまで出したままにし、タイマーの上に解いたケース（例：`PLL A1+`）を出す。「解けなかった」は `DNF` とケース。結果の「取り消す」で 0.00 に戻し、ケースも消す。スキップ・Esc・設定の変更でも 0.00 に戻す。次のスクランブルはすぐに出す
  - ケースの行はスクランブルとタイマーの間に置き、空のときも高さを取っておく（出し入れでタイマー・ボタンの位置が動かないように）。通しでは出さない
- **ヒント**（スタート前だけ押せる）：ケースの名前と、解く手順（自分の手順があればそれ）の最初の3手を出す（前の AUF は出題の向きで変わるので出さない）。もう一度押す（ボタンは「ヒントを隠す」になる）と消す。ヒントを見た問題は、目安以内で解けても練習中にし（「ヒントを見たので練習中にしました」）、タイムを最近の記録に入れない
- 判定（`js/progress.js` の `judge`）：目安以内 → 習得済み、超えた → 練習中。「解けなかった」→ 練習中（タイムは DNF）。「スキップ」は記録せず次へ
- 結果：タイム、判定（例：「✓ 習得済み（8秒以内）」）、**取り消す**（直前の判定とタイムを戻す）、ケースの画像・名前・手順（自分の手順があればそれ）、そのケースの最近のベスト・平均
- 直近の記録：このページを開いてからの結果を最大12件（ケース名とタイム、習得済みは緑・練習中は琥珀）
- 判定したら次の問題（スクランブル）をすぐ出す（結果は前の問題のもの）

## 保存（`js/store.js` 経由。ログイン中はクラウドにも）
- 習得状況：一覧と同じ `progress` を書き換える（`js/progress.js`。一覧と練習で共通）
- `practice`：`{ set, scope, filter, weighted（出題が苦手を多めにか。無ければ true、false はランダム）, thresholds: { pll: 秒, oll: 秒 }（以前の共通の threshold があれば、無い方の目安に使う）, groups: { pll: ["A", "B"], oll: [] }, stats: { 記録のページの表示 }, log: [日時付きの記録], times: { pll: { "A1+": [最近のタイム(秒) 新しい順 最大10件] }, oll: {…} } }`
- URL `?set=oll&scope=nd&filter=new` で設定の初期値を指定できる（その値で保存し直す）

## ほかのページ
- 3ページ（エディタ・PLL一覧・OLL一覧）とプライバシーポリシーのナビバーに「練習 / Practice」
- PLL・OLL 一覧の上部に **練習する** ボタン：今の範囲・絞り込み・選んだグループのまま `practice?set=…&scope=…&filter=…&order=…&groups=…` を開く
  - `groups` は一覧で選んだグループ（`A,B`。覚える順なら段階の番号 `9,24`）。空ならすべて。練習ページはその選択で保存し直す（一覧で何も選んでいなければ、練習ページの選択も外れる）。`order`（PLL だけ）は並び（`learn` / `group`）
- 画像の配色は一覧と同じ（`Progress.displaySettings`）

## 記録（`stats.html`・`js/stats.js`・`css/stats.css`）
- 判定のたびに `practice.log` に `{ at: 日時(ms), set, name, sec(null=解けなかった), status, hint }` を足す（新しい順、最大 2000 件。「取り消す」でその1件も消す）。集計は `js/progress.js` の `addLog`・`summarize`・`daily`・`perCase`
- ナビバーの「記録 / Stats」、練習ページの「すべての記録を見る」から開く。練習ページからは今の種類（OLL は範囲も）を URL（`stats?set=oll&scope=d`）で渡し、記録のページはその種類で開く（表示の設定として保存する）
- 種類（PLL / OLL）・範囲（OLL の No Dot / Dot / All）・期間（7日 / 30日 / すべて）で絞る（`practice.stats` に保存）
- 集計のカード：練習回数、平均（とベスト）、解けなかった回数、習得済みの数（今の習得状況）
- タイムの推移：横軸＝期間内の1回ごとの記録（古い順、1 から数える）、縦軸＝タイム。ライブラリを使わず SVG で描く
  - 通し：点＝1回のタイム、線＝その時点の ao5・ao12（`Progress.rollingAverages`。期間より前の記録も使って出す。DNF・回数が足りないところは線が途切れる）
  - PLL・OLL：ao は出さず、1回ごとのタイムを線で結ぶ（解けなかったところは飛ばして前後を結ぶ）。点の色＝判定（習得済み＝緑、練習中＝琥珀）。破線＝その種類の今の習得の目安
  - DNF は上の端に ×。縦軸の上は ao5・ao12 の最大と1回のタイムの 95% 点の大きい方までにし、それより遅い点は上の端に △（外れ値で線がつぶれないように）
  - マウス・タッチで、いちばん近い記録の縦線と、何回目・日時・タイム（PLL・OLL はケース名も、通しは ao5・ao12 も）を出す
- ケースごとの表：画像・ケース・グループ・習得状況・最近・回数（解けなかった回数）・ベスト・平均・最後に練習した日。見出しを押すと並べ替え。
  - 表の上の切り替えで並びを選ぶ：**苦手順**（既定）/ **グループ順** / **覚える順**（PLL だけ。`CaseSections.hasStages`）。選んだ並びは `practice.stats.sort`・`desc` に保存（`sortV: 2`。苦手順を足す前に保存した並びは使わず苦手順にする）。見出しで別の列を選んだら、切り替えはどれも選ばれていない状態
  - 最近：期間内の直近 10 回の平均（解けた回だけ。解けなかった回があれば赤で「DNF n」を添える。全部解けなかったら「DNF」）。3 回未満は薄く出す（参考値）。`Progress.recentPerCase`
  - 苦手順：最近の遅い順。並べるときは解けなかった回を習得の目安の 2 倍のタイムとして数える（失敗の多いケースが上に来るように）。回数の少ないケースがたまたまの1回で上に来ないよう、全体の平均のタイムで 2 回解いたものとして足した平均で並べる（表に出すのは足す前の平均）
  - グループ順・覚える順：グループ（覚える順の番号）の順、同じグループの中はデータの順
  - ケースを押すと、そのケースを最初に出題する練習ページ（`practice?set=…&case=…`）を開く
- PLL・OLL の表は「ケースごと / 記録の一覧」を切り替えられる（`practice.stats.tab` に保存）。記録の一覧は期間内の記録を新しい順に、日時・ケース・タイム（解けなかった）・判定（ヒントを見たものは「ヒント」）・×
- 記録の削除（PLL・OLL の記録の一覧、通しの記録の一覧）：個別は各行の ×、一括はチェックで選んで「選択した記録を削除（n）」→ 確認 →「削除する」。削除の行の右端の「すべての記録を削除」（小さな赤い文字のリンク。記録が無ければ出さない）は、表示中の種類（PLL / OLL / 通し）の記録を期間・範囲に関係なくすべて消す。押すと「PLL のすべての記録（n 件）を削除しますか？…」と「すべて削除する」「キャンセル」を出す（最初のフォーカスはキャンセル）。どれも削除のあとに「元に戻す」。PLL・OLL で消すのは `practice.log` のその種類の記録だけで、習得状況と練習ページの最近のタイム（`practice.times`）は変えない。種類・表を切り替えたら選択を外す
- 記録の一覧（PLL・OLL・通し）のページ分け：1ページ 50 件（新しい順）。51 件以上あるときだけ、表の下に「215 件中 51〜100 件目」と「‹ 前へ 1 2 3 4 5 次へ ›」を出す（8 ページ以上のときは最初・最後・今の前後だけを出し、あいだは「…」）。見出しのチェック（スマホは削除のバーの「すべて」）は今のページの記録だけを選ぶ・外す。選んだ記録はページを移っても選んだまま。種類・範囲・期間・表を変えたら1ページ目に戻す。削除で件数が減ったら最後のページに収める。下のページ送りで移ったときは表の頭までスクロールを戻す。ページは保存しない
- 別のタブで練習したら、記録のページにも反映する（storage イベント）

## 通し（Full solve）
- 練習ページの種類「PLL | OLL | 通し」の「通し」で、メガミンクスを通しで解くタイムを測る。記録のページにも「通し」
- スクランブル（`js/wca-scramble.js`）：WCA 公式と同じ形式（Pochmann 記法）。1行 = `R±±` と `D±±` を交互に 10 手（R から。`++`・`--` は等確率）＋最後に `U` か `U'`（等確率）、これを 7 行。乱数は `crypto.getRandomValues`。1行ずつ表示し（行の頭をそろえる）、1行おきにうっすら色を付けて（ストライプ）見やすくする。練習ページの結果・記録のページの「見る」も同じ（`WcaScramble.render`、見た目は `css/common.css` の `.scramble-line`）。画像の記法とは別物なので、ケースの確認には使わない
- 設定：インスペクション（15秒）あり / なし。対象・グループ・目安・ヒントは出さない
- タイマー
  - **長押しして離すとスタート**：スペース（スマホはタイマー）を 0.3 秒押すと準備完了（数字が赤 → 緑）、離した瞬間にスタート。短く押しただけでは始まらない。ストップは任意のキー・タップ（PLL・OLL と同じ）
  - インスペクションあり：スペース（タップ）で 15 秒のカウントダウン（残り秒数）。8 秒・12 秒で色が変わる。カウントダウン中にスペースを長押しして離すと計測開始。15 秒を超えて 17 秒までに始めたら +2、17 秒を超えたら DNF（WCA の規則どおり）。インスペクション中の Esc は中止
  - 止めたあとはタイムを 0.00 に戻さず、次のインスペクション・計測が始まるまで出したままにする（+2 は `52.10+`、DNF は `DNF`。結果でペナルティを変えたら表示も変え、削除したら 0.00 に戻す）。次のスクランブルはすぐに出す
  - インスペクション中・計測中もスクランブルは出したまま（PLL・OLL と同じ）
  - 「解けなかった」「スキップ」「ヒント」のボタンは出さない。解けなかったときは、結果の OK / +2 / DNF で DNF を付ける
- 結果：タイム（+2 なら `52.10+`）、**OK / +2 / DNF** の切り替え（あとから変えられる）、**削除**、スクランブル
- 直近の記録の上に、今の ao5・ao12、ベスト（単発・ao5・ao12）。直近の記録は保存してある最新 12 件
- 平均（`js/progress.js`）：`average(recs, n)` は直近 n 回から最速と最遅を除いた平均。DNF は最遅とみなし、DNF が2つ以上なら DNF。足りなければ「–」。`bestAverage`・`bestSingle`・`effectiveTime`（+2 込みのタイム）
- 保存：`practice.full = { inspection, log: [{ at, sec, penalty: '' | '+2' | 'DNF', s }] }`（新しい順、最大 2000 件。ログイン中はアカウントにも）。習得状況は変えない
  - `s` はスクランブルの短い形：77 か所（各行の ++/-- と U/U'）を 1 ビットずつにし、6 ビットずつ base64url にした 13 文字（`WcaScramble.encode`・`decode`）。1件 約 70 文字で、2000 件でも約 14 万文字（アカウントの保存の上限 50 万文字に、PLL・OLL の記録 2000 件（約 18 万文字）と合わせて収まる）
  - 以前の形（全文の `scramble`）の記録は、練習ページを開いたときに短い形に直して保存し直す。表示は `WcaScramble.textOf`（どちらの形も読める）
  - PLL・OLL の記録（`practice.log`）は PLL と OLL を合わせて最新 2000 件
- 記録の一覧のスマホ表示（幅 576px 未満）：横にスクロールしないよう、1件を2段にまとめる（1段目：チェック・タイム・見る・×、2段目：日時・ao5・ao12）。見出しの行は隠し、「すべて選ぶ」は削除のバーに出す
- 記録の削除（記録のページの「通し」の記録の一覧）
  - 個別：各行の右の × で、その1件をすぐに削除する
  - 一括：各行の左のチェックで選び（見出しのチェックで表示中をすべて選ぶ・外す）、「選択した記録を削除（n）」→「n 件の記録を削除しますか？」→「削除する」で削除する。期間を変えて見えなくなった記録は選択から外す
  - どちらも削除のあとに「n 件の記録を削除しました。 元に戻す」を出す。元に戻すと、削除したあとに増えた記録も残したまま、消した記録を日時の順に戻す
  - 練習ページの結果の「削除」（直前の1件）は今までどおり
- 記録のページ（通し）：カード（回数と DNF の数、ベスト、ベスト ao5（今の ao5）、ベスト ao12（今の ao12））、タイムの推移（点＝タイム、線＝ao5・ao12）、記録の一覧（日時・タイム・その時点の ao5・ao12・スクランブルは「見る」で、その行のすぐ下に表の幅いっぱいの行として開く。列の幅は変えない。「閉じる」で閉じる）
- タイムの表示：60 秒以上は分表記（例：`1:05.23`。`js/progress.js` の `formatTime`）。練習ページのタイマー・結果・直近の記録・ao5/ao12、記録のページのカード・表・グラフの目盛りとグラフの値で使う
