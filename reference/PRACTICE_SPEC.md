# 練習機能の仕様

## 目的
スクランブルで手元のパズルを崩し、解くタイムを測って、PLL・OLL を覚えているかを確かめる。
目安の時間（しきい値）以内に解けたケースは自動で「習得済み」、超えた・解けなかったケースは「練習中」にする。

## データ
- 元データ：`pll/scrambles.json`・`oll/scrambles.json`（`{ ケース番号: [スクランブル, ...] }`。ケース番号は `algs_info.json` と同じ）
- 生成：`node tools/build-pll-data.js`・`node tools/build-oll-data.js` で、`js/pll-data.js` などと一緒に `js/pll-scrambles.js`・`js/oll-scrambles.js`（`window.PLL_SCRAMBLES = { "A1+": [...] }`）を作る（`tools/scrambles-lib.js`）
  - 各スクランブルで崩した状態が、そのケースになる（既定の手順で AUF を除いて揃う）かを確かめ、だめならエラーで止める（`js/case-check.js` の `fitSetup`）
  - 記法は読み替える（`Br` → `BR` など）
  - 練習ページだけが読み込む（エディタ・一覧は重くならない）

## 練習ページ（`practice.html`・`js/practice.js`・`css/practice.css`）
- 設定（上部）
  - 種類：PLL / OLL。OLL のときは範囲：No Dot / Dot / All
  - 対象：未習得 / 練習中 / 習得済み / すべて（それぞれ件数付き）
  - 習得の目安：5秒 / 8秒 / 10秒 / 15秒、または数値を入力（1〜120 秒）
- 出題：対象に当てはまるケースからランダム（直前と同じケースは避ける）、そのケースのスクランブルからランダムに選び、前後にランダムな AUF（それぞれ 0〜4 回）を足す（もともと前後にある U とはまとめる。例：`U R … U'` に前 U・後 U を足すと `U2 R …`）。前後の AUF を足しても同じケースのままで、崩れ方の向きが毎回変わる。ケースの名前と画像は解き終わるまで出さない。対象が0件なら「対象のケースがありません」
- タイマー
  - スペースキーを押した瞬間にスタート（画面ではタイマーの数字をタップした瞬間）。計測中は数字を青にする
  - 計測中は何かのキー（画面ではどこかをタップ）でストップ。Esc は中止（記録しない）
  - キーの押しっぱなしによる繰り返しは無視する（スタートしたスペースを押し続けても止まらない）
  - 計測中はスクランブルと説明を隠す。止めたタップでそのままボタンを押さないよう、止めてから 0.4 秒はボタンを無視する
- **ヒント**（スタート前だけ押せる）：ケースの名前と、解く手順（自分の手順があればそれ）の最初の3手を出す（前の AUF は出題の向きで変わるので出さない）。もう一度押す（ボタンは「ヒントを隠す」になる）と消す。ヒントを見た問題は、目安以内で解けても練習中にし（「ヒントを見たので練習中にしました」）、タイムを最近の記録に入れない
- 判定（`js/progress.js` の `judge`）：目安以内 → 習得済み、超えた → 練習中。「解けなかった」→ 練習中（タイムは DNF）。「スキップ」は記録せず次へ
- 結果：タイム、判定（例：「✓ 習得済みにしました（目安 8 秒以内）」）、**取り消す**（直前の判定とタイムを戻す）、ケースの画像・名前・手順（自分の手順があればそれ）、そのケースの最近のベスト・平均
- 直近の記録：このページを開いてからの結果を最大12件（ケース名とタイム、習得済みは緑・練習中は琥珀）
- 判定したら次の問題（スクランブル）をすぐ出す（結果は前の問題のもの）

## 保存（`js/store.js` 経由。ログイン中はクラウドにも）
- 覚えた度：一覧と同じ `progress` を書き換える（`js/progress.js`。一覧と練習で共通）
- `practice`：`{ set, scope, filter, threshold, times: { pll: { "A1+": [最近のタイム(秒) 新しい順 最大10件] }, oll: {…} } }`
- URL `?set=oll&scope=nd&filter=new` で設定の初期値を指定できる（その値で保存し直す）

## ほかのページ
- 3ページ（エディタ・PLL一覧・OLL一覧）とプライバシーポリシーのナビバーに「練習 / Practice」
- PLL・OLL 一覧の上部に **練習する** ボタン：今の範囲・絞り込みのまま `practice.html?set=…&scope=…&filter=…` を開く
- 画像の配色は一覧と同じ（`Progress.displaySettings`）
